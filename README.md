## Komunikacja między modułami
W folderze kontrakty znajdują się "kontrakty" dotyczące poszczególnych członków zespołu. Opisują one planowany sposób komunikacji między modułami, np. udostępniane metody, dane. W normalnym języku wystarczyłby pewnie dobry interfejs, ale wybraliśmy pythona więc jest jak jest.
